# Kali Linux Journey & Terminal Exploration

Welcome to my repository documenting my journey with **Kali Linux**. Rather than running it inside a virtual machine, I have installed Kali Linux natively as a dedicated operating system on my machine, allowing for a fully immersive Linux and cybersecurity exploration environment.

## Overview

This repository serves as a personal log and showcase of my initial steps, configurations, and terminal-based interactions within a native Kali Linux environment. It captures the foundational phase of setting up the system and getting comfortable with essential command-line tools.

## Key Highlights

* **Bare-Metal Installation:** Running Kali Linux directly as the host OS for optimal performance, hardware access, and a deeper understanding of Linux system administration.
* **Terminal Proficiency:** Practicing essential shell commands, navigating the Linux filesystem, managing permissions, and utilizing built-in utilities.
* **Video Demonstration:** Includes an introductory video walkthrough showcasing the freshly installed desktop environment and live terminal command execution.
